> Сводка всех числовых допущений из четырёх аналитических документов

## 2. Базовая unit-экономика (P&L на одну транзакцию)

Канонический разбор одного подарка **₪450**. Отрицательные строки — расходы.

| Строка | Сумма | Формула / источник |
|---|---:|---|
| Цена подарка (ASP) | ₪450 | средний чек |
| + Комиссия платформы (take rate 33%) | +₪148 | 450 × 33% |
| + Бонус breakage (~13% не погашается) | +₪39 | чистая маржа без затрат ספק |
| − Выплата поставщику | −₪262 | 450 × (1−33%) × (1−13%) |
| − Коробка (35% физ. × ₪38) | −₪13 | physical mix |
| − Доставка Vector 1 (35% физ. × ₪65) | −₪23 | physical mix |
| − Эквайринг (2.5%) | −₪11 | 450 × 2.5% |
| − AI / Tech на заказ | −₪9 | |
| − Поддержка клиентов | −₪12 | |
| **= Вклад до маркетинга** | **≈ ₪119** | |
| − CAC (привлечение клиента) | −₪55 | |
| **= Чистая маржа с транзакции** | **≈ ₪64** | база |

> **Примечание.** Калькулятор в `vauarch.jsx` при дефолтных параметрах даёт **₪64**.
> Вкладка «Рост» того же файла и `vauanalysis.jsx` используют **₪77** — см. §9 (расхождения).

## 9. Зафиксированные расхождения (требуют решения)

| # | Что | Где | Рекомендация |
|---|---|---|---|
| 1 | Чистая маржа/tx: **₪64** vs **₪77** | `vaufinance` / калькулятор `vauarch` дают ₪64; вкладка «Рост» `vauarch` и `vauanalysis` — ₪77 | Зафиксировать **₪64** как базу (следует из модели при дефолтах); ₪77 достижима только при нулевом physical mix или сниженном CAC — оформить как отдельный «оптимизированный» кейс |
| 2 | Объём base year 1: **8 580** vs **9 730** транзакций | `vaufinance` (8 580) vs `vauarch`/Growth (9 730) | Свести к одной месячной кривой ramp-up |
| 3 | CAC base: **₪55** (модель) vs blended **₪63** (микс каналов) | §3 vs §5 | Разъяснить: ₪55 — целевой после оптимизации; ₪63 — стартовый взвешенный |
| 4 | Нейминг бренда: **VAU** vs **Epicent / אפיסנט** | код/материалы | ✅ Устранено — унифицировано на **VAU** во всём коде |
